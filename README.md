# logica-de-programacao
Exercícios que estou resolvendo enquanto estudo Lógica de Programação com o VisualG, seguindo o curso de Algoritmos do Gustavo Guanabara (Curso em Vídeo).

## Exercícios

- Analisador de valores (Utilização da estrutura de repetição "para", afim de analisar a soma dos valores, a média dos valores, quantidade de valores divisíveis por 5, a soma de todos os números pares e a quantidade de números nulos.)

## Como executar

- Abra o arquivo '.alg' no VisualG 3 execute clicando em "RUN" ou F9.


## Objetivo

Construir uma base sólida em lógica antes de seguir para uma linguagem de programação exata.
